# ADR-0014 — Every screen shows the data trail

> Portuguese version: [`docs/pt-BR/adr/0014-toda-tela-mostra-a-trilha-do-dado.md`](../../pt-BR/adr/0014-toda-tela-mostra-a-trilha-do-dado.md).

Status: accepted, 2026-11-14.

**Context.** The challenge asks for sources credited inside the game and science traceable by the judges. A child who wants to know more needs to find the answer right there.
**Decision.** Each piece of data has a data card with source, place and date, processing, use in the game, simplification, parallel and an explanation in kid language with an everyday example. The cards on the screens, the "The science behind" page and a public file come from the same source. A screen without a card is not accepted.
**Consequences.** Each new piece of data costs a complete card in both languages. Validity no longer depends on the README.
