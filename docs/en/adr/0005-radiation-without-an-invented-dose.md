# ADR-0005 — Radiation without an invented dose

> Portuguese version: [`docs/pt-BR/adr/0005-radiacao-sem-dose-inventada.md`](../../pt-BR/adr/0005-radiacao-sem-dose-inventada.md).

Status: accepted, 2026-11-14.

**Context.** Radiation shielding is a mandatory theme, but we have no defensible model of dose on Mars.
**Decision.** The game shows crew exposure in three levels (low, medium, high), driven by real DONKI events and by use of the Shield. Real dose readings appear only as informational RadLab cards, labeled as measured on the Space Station.
**Consequences.** No Martian dose number is fabricated. The child learns the trade-off (the shield costs energy) without false precision.
