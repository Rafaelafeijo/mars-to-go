# ADR-0010 — No account, no database, progress on the device

> Portuguese version: [`docs/pt-BR/adr/0010-sem-conta-sem-banco-progresso-no-aparelho.md`](../../pt-BR/adr/0010-sem-conta-sem-banco-progresso-no-aparelho.md).

Status: accepted, 2026-11-14.

**Context.** The challenge values playing with no download and no account; the audience is children.
**Decision.** No personal data. Progress in local storage. The API has no database.
**Consequences.** No syncing between devices.
