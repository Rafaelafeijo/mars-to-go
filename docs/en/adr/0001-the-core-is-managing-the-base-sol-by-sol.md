# ADR-0001 — The core is managing the base, sol by sol

> Portuguese version: [`docs/pt-BR/adr/0001-o-nucleo-e-a-gestao-da-base-sol-a-sol.md`](../../pt-BR/adr/0001-o-nucleo-e-a-gestao-da-base-sol-a-sol.md).

Status: accepted, 2026-11-14.

**Context.** The challenge asks for children to manage an outpost and live with the consequences of their choices over a simulated mission.
**Decision.** The game is a 7-sol mission at a base in Jezero. The journey and the landing are only scene-setting.
**Consequences.** Anything that does not change one of the base's reserves is secondary.
