# ADR-0012 — Bilingual game and documentation; code in English

> Portuguese version: [`docs/pt-BR/adr/0012-jogo-e-documentacao-bilingues-codigo-em-ingles.md`](../../pt-BR/adr/0012-jogo-e-documentacao-bilingues-codigo-em-ingles.md).

Status: accepted, 2026-11-14.

**Context.** The game is created in Portuguese and needs to reach the world. The submission guide requires English on the project page and in the linked materials.
**Decision.** Full Portuguese and English interface from the MVP. Code, comments and commits in English. Documentation in `docs/en/` (default) and `docs/pt-BR/`. Project page, demo and slides in English only.
**Consequences.** Every new text is born in both languages. Spanish is left for after the event.
