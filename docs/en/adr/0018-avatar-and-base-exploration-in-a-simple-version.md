# ADR-0018 — Avatar and base exploration in a simple version

> Portuguese version: [`docs/pt-BR/adr/0018-avatar-e-exploracao-da-base-em-versao-simples.md`](../../pt-BR/adr/0018-avatar-e-exploracao-da-base-em-versao-simples.md).

Status: accepted, 2026-11-14.

**Context.** Customization and exploration increase engagement and count toward the Creativity criterion, but they don't teach the central trade-off.
**Decision.** Avatar with suit color, emblem and a codename from a ready-made list. The base as a tappable scene that opens the data cards. Both come in after the core mechanics and are the first to go if time runs short.
**Consequences.** No text typed by the child, therefore no personal data.
