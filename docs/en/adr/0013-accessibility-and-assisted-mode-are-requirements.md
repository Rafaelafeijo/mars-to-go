# ADR-0013 — Accessibility and assisted mode are requirements

> Portuguese version: [`docs/pt-BR/adr/0013-acessibilidade-e-modo-assistido-sao-requisito.md`](../../pt-BR/adr/0013-acessibilidade-e-modo-assistido-sao-requisito.md).

Status: accepted, 2026-11-14.

**Context.** Ten-second timers exclude some children aged 7 to 9.
**Decision.** WCAG 2.2 AA on decision screens. Every timer has an assisted mode with the same learning. Sound optional.
**Consequences.** Every component goes through a checklist.
