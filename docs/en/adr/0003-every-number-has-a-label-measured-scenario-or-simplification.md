# ADR-0003 — Every number has a label: measured, scenario or simplification

> Portuguese version: [`docs/pt-BR/adr/0003-todo-numero-tem-rotulo-medido-cenario-ou-simplificacao.md`](../../pt-BR/adr/0003-todo-numero-tem-rotulo-medido-cenario-ou-simplificacao.md).

Status: accepted, 2026-11-14.

**Context.** The game mixes real data with a base that does not exist. The challenge asks for credited sources and forbids presenting static data as live.
**Decision.** No constant outside the single science file. Each one has a label, source, place and date, and the label appears in the interface, with "live" or "archive".
**Consequences.** Extra work per number; in return, the science is traceable by the judges.
