# docs/playtest

Evidence from real playtests (ADR-0029). Filled in `docs/en/PLAYTEST.md` / `docs/pt-BR/PLAYTEST.md`.

What goes here:
- `roundN-session.json` — the file from "Export session" (anonymous events only).
- `rN-K-before.png`, `rN-K-after.png` — screenshots of the game before and after each change.
- A short screen recording **without an audio track** (checked before commit).

Never: a name, photo, video, voice or likeness of the tester or any minor.
